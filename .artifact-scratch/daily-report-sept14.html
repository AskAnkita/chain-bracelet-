08

Diagnosed the local checkout 502

Diagnosed

Traced the "Response body already used" crash to Shopify CLI's own dev proxy, which can't rewrite the redirect to hosted checkout — not something in the theme.

Fix: test checkout on the real *.myshopify.com preview link CLI prints on start, not 127.0.0.1:9292. --live-reload=full-page is a fallback if localhost checkout matters.

09

Built the wishlist / favorites feature

Needs the admin page

The header already had a heart icon and counter with nothing behind them. Built out the whole feature: a heart toggle on every product card and on the product page, shared storage so the count badge and every button stay in sync, and a dedicated Wishlist page that lists saved products with a remove-from-here heart.

Product cards reveal the heart on hover (matching the existing "+" quick-add button), except once favorited — a saved heart stays visible so it's clear at a glance what's been saved.
